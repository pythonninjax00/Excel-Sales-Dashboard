
## Project Overview
An interactive sales dashboard developed in Microsoft Excel to analyse sales performance across different months, countries, and sales channels.

The project uses Excel formulas and PivotTables to organise sales data, calculate key performance metrics, and present insights through a dashboard.

## Objectives
- Analyse overall sales performance
- Track revenue, gross profit, and units sold
- Identify monthly sales trends
- Compare sales performance across countries
- Evaluate sales channel contribution
- Present business insights through a dashboard

## Tools & Techniques
- Microsoft Excel
- Excel Formulas
- PivotTables
- Data Analysis
- Dashboard Design
- Data Visualization

## Workbook Structure

| Sheet | Description |
|---|---|
| `Data` | Sales dataset and calculated fields |
| `Detail1` | Detailed sales records |
| `Pivot tables` | Summary tables supporting the analysis |
| `Dashboard` | Visual overview of sales performance |

## Key Metrics
- Total Revenue
- Total Gross Profit
- Gross Profit Margin
- Units Sold
- Order Count

## Analysis
The dashboard provides insights into:
- Monthly sales performance
- Country-level sales
- Sales channel contribution
- Revenue and profitability trends

## How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Navigate to the `Dashboard` sheet to view the dashboard.
4. Explore the underlying data and PivotTables for further analysis.
